# AI Orchestra — согласованная схема AI-ресурсов

**Владелец:** Максим Анисимов. **Решение:** 07.11.2026.
**Статус:** политика согласована; production-переключений и новых API-запросов этим документом не выполняется.

## Разрешённые маршруты

| Сценарий | Маршрут | Финансовый и контрольный режим |
| --- | --- | --- |
| Разработка, отладка, анализ, код-ревью с участием пользователя | ChatGPT и Codex в пределах подписки владельца | Использовать доступные инструменты/сессии, фиксировать реальные тесты и PR. Не объявлять чат-ревью серверным independent run. |
| Автоматическое серверное inference AI Orchestra | Прямой **OpenAI API** через внутренний Model Router/Gateway | Только при активированных API-кредитах, проверенном остатке и отключённом несанкционированном платном продолжении. Нет подтверждения — отказ без fallback. |
| High-assurance review Arvento | Изолированный `opencode-review`, неизменяемая Git-версия, официальный OpenAI API | Отдельный staging, только чтение, подтверждённая модель/токены, единичный verdict и аудит. Runtime остаётся выключенным до приёмки. |
| AITunnel, Anthropic, Google и иные платные сторонние провайдеры | **Не разрешены** | Не использовать даже при недоступности OpenAI и не включать автоматически. |

## Как применять

1. Для GitHub/Arvento продолжать обычный workflow: отдельная ветка, CI, дополнительное ревью ChatGPT/Codex, независимая приёмка, затем отдельный release gate.
2. OpenAI API-кредиты ChatGPT Pro **могут** предоставляться после привязки подписки к API-организации владельца. Проверить статус в ChatGPT Settings → Billing / OpenAI Platform Billing; не считать кредитный баланс подтверждённым без фактической проверки. Документация: https://developers.openai.com/api/docs/guides/chatgpt-api-credits
3. API-ключ находится **только** в защищённом `.env.providers` Model Router; не копировать его в git, чат, лог, контейнер OpenCode или задачи. Не использовать ранее опубликованные в сообщениях ключи без перевыпуска через безопасный канал.
4. Перед каждым unattended AI-запуском проверить остаток и конфигурацию платного продолжения/Auto Recharge на уровне API-организации. Если технически нельзя гарантировать предел расходов — остановить запуск и запросить решение владельца.
5. Для PR Arvento #31 использовать зафиксированный исходный Git SHA и маршрут `opencode-review` после отдельной стендовой приёмки. Профиль `config/model-router.assured-openai.yaml` + `compose.assured-openai.yml` предназначен **только для изолированного review-стенда**; он не содержит других моделей и не может подменять общий работающий Model Router.
6. Старые `shared`/`separate` профили в репозитории сохраняются для воспроизводимости существующих установок, но **не являются действующим разрешением** на стороннее платное inference. Их удаление/миграцию планировать отдельным контролируемым изменением.
