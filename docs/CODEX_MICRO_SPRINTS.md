# Подписочный оркестр: микроспринты

Дата: 03.10.2026. Это операторский маршрут, не автоматическая API-очередь.

## Модель и расходы

`orchestra-task`: ChatGPT subscription, `gpt-6-astra`, `xhigh`, Standard. Проверка тарифного состояния и нулевого баланса перед каждым запуском сохранена без ослабления. Платные API и автоматическая покупка кредитов запрещены; включённая квота подписки расходуется.

Предыдущие задания остановлены локальным лимитом 900 секунд; подтверждённых rate-limit ошибок в их event logs нет. Поэтому модель не понижена. При будущем подтверждённом ограничении конкретной модели оператор проверяет доступность альтернативы и включённую квоту через защищённый preflight. Изменение модели — отдельное проверенное изменение. Общая исчерпанная квота или неизвестный billing требуют остановки, а не платного fallback.

## Размер задач

Один запуск — один контракт или небольшое изменение с отдельным критерием приёмки. Архитектор не реализует модуль; разработчик не перепроектирует проект; QA проверяет конкретный commit. Каждый запуск имеет отдельный worktree и ID. Модельные запуски выполняются последовательно.

Default process budget: architect/reviewer/qa — 300 секунд; developer — 420 секунд. Явный `--timeout` допустим в пределах 60..600 секунд. Это технические дедлайны, не оценки длительности разработки. Большая задача дробится.

Prompt содержит base commit, точные файлы/диапазоны чтения, разрешённые файлы изменения, критерии приёмки, целевую команду тестирования и короткий итог. Полный make check выполняет интегратор после объединения, а не каждый агент на каждом шаге.

Порядок: A — контракт; D1 — схема; D2 — сервис; D3 — HTTP; D4 — UI; Q — негативные тесты; I — интеграция. Следующий блок начинается с проверенной контрольной точки.

## Контроль результата

До inference создаётся run.json с outcome=running. Завершение фиксирует exit_code, outcome, timeout_seconds, непустой final.txt и событие turn.completed. Нулевой exit code без двух последних признаков становится incomplete_result (65); такой запуск не является завершённым review.

Логи событий и stderr сохраняются файлами 0600. При дедлайне завершается POSIX process group, включая дочерние процессы, пережившие TERM; outcome=local_timeout, код 124. Worktree и журналы сохраняются. Автоматического повторения или смены платёжного маршрута нет.

Перед повтором интегратор проверяет частичные изменения, сохраняет выбранный patch и создаёт более узкую задачу. Слепой повтор большого prompt не допускается.

## Проверка

10 локальных проверок без inference: worktree и артефакты, запрет API-ключа, dirty repo, process-group timeout, сохранение частичных файлов/логов, обязательные final и turn.completed, ошибочные события, guard exit 78, default/override дедлайны.

Pytest отсутствовал в проверенных интерпретаторах; pytest-совместимые функции вызваны напрямую, с отдельным TemporaryDirectory на каждый тест. Лог: results/micro-runner-20261003/tests.log под домашним каталогом codex-worker.

Версионируемый источник установленного /usr/local/bin/orchestra-task: scripts/orchestra_task_entrypoint.py. Исполнитель: scripts/codex_task.py в операторском checkout. Production control-plane и платные workers не изменялись.
