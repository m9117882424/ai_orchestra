## Как запускается работа

| Маршрут | Текущий режим |
| --- | --- |
| Операторский Codex CLI | Рабочий запуск по подписке ChatGPT Pro в отдельной Git-копии. Отчёты и журнал CLI хранятся в артефактах оператора. Такие запуски ведутся отдельно от `execution_runs` кабинета. |
| Кнопка «Запустить» в рабочем кабинете | Для development-задач по умолчанию выбирает `codex-subscription`. Серверная часть выложена, постоянный воркер и файл авторизации брокера ожидают отдельной приёмки. Пока файл авторизации отсутствует, сервер возвращает HTTP 503 до создания запуска. |
| Запуск из кабинета на стенде | Диспетчер забрал задачу из очереди и передал воркеру одну рабочую копию только для чтения. Три роли сохранили итоговый пакет. После перезапуска кабинета и PostgreSQL отчёт открылся по прямой ссылке с тем же SHA-256. Повторный старт отклонён. |
| OpenCode / Model Router | Опциональный маршрут. На рабочем контуре флаг платного выполнения выключен, Model Router, Model Gateway и старый execution-worker остановлены. Автоматического переключения на платный маршрут нет. |

На стенде смоделировано истечение аренды до старта модели. Новый воркер получил тот же запуск, старое подтверждение было отклонено. Выполнены 373 теста Control Plane и Runner.
